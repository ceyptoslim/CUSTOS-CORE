## Why This CLA Exists

CUSTOS-CORE is dual-licensed under AGPL-3.0 (open source) and a proprietary
commercial license. To maintain this dual-license model, every contributor
must grant the project owner the right to relicense their contribution
commercially. Without this agreement, a single contributor could block the
commercial license by withholding permission.

This CLA protects:
1. The project's ability to offer a commercial license alongside AGPL-3.0
2. Contributors (you retain your copyright; you only grant a license)
3. Users (clear provenance for every line of code)

## How to Sign

### For Individual Contributors

Add your GitHub username to the `CLA_SIGNERS.md` file in the same pull
request that contains your Contribution. By adding your username, you
confirm that you have read and agree to the terms of this CLA.

```markdown
| @your-github-username | Individual | Date | v1.0 |
```

### For Corporate Contributors

Add your corporation's name and the authorized signatory's GitHub
username to `CLA_SIGNERS.md`:

```markdown
| @signatory-username | Corporation Name | Date | v1.0 |
```

If your corporation cannot sign via this mechanism, contact
frolifeproductions@gmail.com to arrange an offline signature.

## Enforcement

A GitHub Action automatically verifies that every pull request author
has signed this CLA. Pull requests from unsigned contributors will be
blocked until the CLA is signed.

The Maintainer reserves the right to override the automated check in
exceptional circumstances (e.g., clearly trivial typo fixes).
